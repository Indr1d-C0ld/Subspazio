# Caratteri dei temi grafici

Ospitati qui, non caricati da server esterni: i browser dei giocatori non
chiamano nessuno fuori da SubSpazio. Tutti sotto **SIL Open Font License 1.1**
(il testo di ciascuna licenza e' nel file `OFL-<famiglia>.txt` accanto),
scaricati il 09/10/2026 da Google Fonts, solo il sottoinsieme latino in woff2.

| File | Famiglia | Tema |
|---|---|---|
| `antonio-var.woff2` | Antonio (variabile, 100-700) | LCARS |
| `sharetechmono-400.woff2` | Share Tech Mono | Terminale MU/TH/UR, e numeri in Cockpit, Cintura, Neon |
| `vt323-400.woff2` | VT323 | Terminale MU/TH/UR (titoli) |
| `orbitron-var.woff2` | Orbitron (variabile, 400-900) | Cockpit (titoli ed etichette) |
| `exo2-var.woff2` | Exo 2 (variabile, 100-900) | Cockpit (testo) |
| `titilliumweb-300/400/600.woff2` | Titillium Web | Cintura |
| `audiowide-400.woff2` | Audiowide | Neon (titoli) |
| `chakrapetch-400/600.woff2` | Chakra Petch | Neon (testo) |

Il tema «Console» usa i caratteri di sistema. Ogni foglio in
`assets/css/temi/` dichiara con `@font-face` solo i caratteri che usa, quindi
un giocatore scarica soltanto quelli del suo tema.
